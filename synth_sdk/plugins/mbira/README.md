# MBIRA

Original Hundekraft engine for kennel.

Modal thumb-piano synthesis with four decaying partials, strike transient, box resonance, Double, Wah and Buzz. The core supplies six voices and the T2 envelope. Voice setup reuses bounded coefficient history; cache identity includes the parameters needed to reproduce the same coefficients.

The manifest and source define defaults, secondary controls and screen nodes. Keep per-voice state separate, preserve stock voice ownership and retain the source copyright/license notices.
